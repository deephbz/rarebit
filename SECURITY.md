# Security

Report a security issue privately through GitHub Security Advisories for
`deephbz/rarebit`. Do not put credentials, Session content, or Recall files in
a public issue.

For non-sensitive help, use the GitHub issue tracker:
https://github.com/deephbz/rarebit/issues

This alpha has no response-time commitment. Include the Rarebit version, Pi
version, Node version, and safe reproduction steps.
