First useful result

First result in
two steps.

Rarebit is public alpha software for Node 22+ and Pi 0.83+. Pin a version for a reproducible setup.

terminal
# From a shell: extract selected prose
# Session files live under ~/.pi/agent/sessions/; a Session ID also works
$ npx --package @hypercarrier/rarebit@0.2.0 rarebit extract \
    --session <path-or-session-id> --json > selected-prose.json
$ jq -r '.rarebits[] | "\(.role): \(.text)"' selected-prose.json

# Add the Pi extension for Recall and Fork, then restart Pi
$ pi install npm:@hypercarrier/rarebit@0.2.0

Extract prints selected prose. The agent provider sees what Recall asks the agent to read. Read the privacy guidance.
