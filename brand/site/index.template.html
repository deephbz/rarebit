__INSTALL__

Rarebit is public alpha software for Node 22+ and Pi 0.83+. After a restart, ask Pi to recall what matters: /rarebit recall What should guide the next turn?

Recall sends your model provider what the agent reads. Read the privacy guidance.

For scripts: print the rare bits as JSON 
__EXTRACT__

Session files live under ~/.pi/agent/sessions/. A Session ID also works.
